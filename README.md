# Brazilian E-Commerce Analytics

## Project Overview
An end-to-end Data Analytics and Business Intelligence project using the Brazilian E-Commerce Public Dataset by Olist.

This project explores e-commerce business performance through SQL Server and Microsoft Power BI, transforming multiple related transactional tables into an interactive five-page analytical report.

## Tools & Technologies
- Microsoft SQL Server
- SQL
- Microsoft Power BI
- DAX

## Dashboard Pages

1. **Executive Overview** – Overall business performance, revenue, orders, and customers.
2. **Customer Analysis** – Customer acquisition, retention, repeat purchases, and purchasing behavior.
3. **Sales Analysis** – Revenue trends, payment methods, quarterly sales, and monthly growth.
4. **Product & Seller Analysis** – Product category performance and seller contributions.
5. **Delivery & Review Analysis** – Delivery performance, late deliveries, and customer feedback.

## Project Workflow
1. Data import into SQL Server.
2. Data cleaning and validation.
3. Exploratory data analysis using SQL.
4. Data modelling using fact and dimension tables.
5. DAX measure development.
6. Interactive dashboard development in Power BI.

## Repository Structure
- `Dashboard/` – Power BI dashboard (.pbix)
- `Documentation/` – Detailed project report (.pdf)

## Dataset
Brazilian E-Commerce Public Dataset by Olist.

## Project Scope
This project focuses on descriptive and diagnostic analysis of historical e-commerce data. It does not claim to provide predictive forecasting or causal analysis.
